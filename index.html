Quick start in 5 minutes

1
Connect the board
Use a USB cable to connect the module to your computer. The board supports USB power and data.
2
Test with firmware
Use the included flash download tool and the supplied firmware BIN file to verify the screen and touch hardware quickly.
3
Arduino setup
Install Arduino IDE, add ESP32 board support, and install the TFT_eSPI library. Then configure the library for your board version.
4
MicroPython setup
Flash a MicroPython firmware build for ESP32, upload an ST7789-compatible driver module, then run the example script shown below.

Arduino example

// TFT_eSPI User_Setup.h:
// #define ST7789_DRIVER
// #define TFT_WIDTH  240
// #define TFT_HEIGHT 320
// #define TFT_MISO   12
// #define TFT_MOSI   13
// #define TFT_SCLK   14
// #define TFT_CS     15
// #define TFT_DC      2
// #define TFT_RST    -1
// #define TFT_BL     21

#include <TFT_eSPI.h>

TFT_eSPI tft = TFT_eSPI();

void setup() {
  tft.init();
  tft.setRotation(1);
  tft.fillScreen(TFT_BLACK);
  tft.setTextColor(TFT_WHITE, TFT_BLACK);
  tft.drawString("ESP32 + ST7789", 40, 120, 4);
}

void loop() {
}

MicroPython example

from machine import Pin, SPI
import st7789py as st7789

# Display SPI pins for ESP32-2432S028:
# SCLK=GPIO14, MOSI=GPIO13, MISO=GPIO12
spi = SPI(1, baudrate=40000000,
          sck=Pin(14), mosi=Pin(13), miso=Pin(12))

display = st7789.ST7789(
    spi, 240, 320,
    reset=None,
    dc=Pin(2),
    cs=Pin(15),
    backlight=Pin(21)
)

display.init()
display.fill(st7789.BLACK)
display.text("ESP32 + ST7789", 30, 120, st7789.WHITE)

FAQ and troubleshooting

The screen does not light up. What should I check?

Check USB power first, then confirm the board was flashed successfully. If your firmware controls backlight separately, verify the backlight pin configuration.

The display shows noise or corrupted graphics.

This is usually caused by incorrect display pin mapping, SPI configuration, or a mismatched TFT_eSPI setup file. Verify the board-specific library settings.

Touch input is not responding.

Confirm the XPT2046 touch pins match the board diagram. Touch also needs the correct CS and IRQ configuration in your code.

The board cannot be detected for flashing.

Try a different USB cable, install the correct serial driver if required by your PC, and confirm the correct COM port is selected in the flash tool or IDE.

Which language should beginners start with?

Arduino is the easiest starting point because the ecosystem has more display examples. MicroPython is a good next step for faster experimentation.

Can I use this board for customer-facing UI prototypes?

Yes. It is well suited for proof-of-concept interfaces, device dashboards, and internal demo systems. For production, validate long-term power and enclosure requirements.
